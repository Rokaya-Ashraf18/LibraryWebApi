# Library Web API

A backend RESTful API for an online library system where users can browse books and place orders.

## 🛠️ Technologies

* C#
* ASP.NET Core Web API
* Entity Framework Core
* SQL Server
* LINQ
* ASP.NET Core Identity
* RESTful APIs
* Swagger / OpenAPI
* Repository Pattern
* Service Layer

## ✨ Features

* Book management
* Category management
* Author management
* Book-category relationships
* Book-author relationships
* Order and OrderItem management
* Stock quantity management
* DTO-based API responses
* Asynchronous database operations
* Entity Framework Core relationships and eager loading
* User management with ASP.NET Core Identity
* Swagger API documentation

## 🏗️ Architecture

The project follows a layered architecture:

**Controller → Service → Repository → Entity Framework Core → SQL Server**

### Main Entities

* `Book`
* `Author`
* `Category`
* `Order`
* `OrderItem`
* `ApplicationUser`

## 📌 What I Practiced

This project helped me practice building a real-world backend application with ASP.NET Core, including API design, database relationships, LINQ, EF Core, DTOs, dependency injection, asynchronous programming, and separation of concerns.
